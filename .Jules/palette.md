## 2024-05-18 - Missing Accessible Names in Admin Controls\n**Learning:** The `AdminPanel.tsx` component relies heavily on unlabelled icon-only buttons (`lucide-react`) for critical administrative and destructive actions (e.g., Delete Episode, Delete Task). This causes significant accessibility barriers for screen reader users traversing complex table/list elements.\n**Action:** Always verify that interactive icon components are either wrapped in an accessible `<button aria-label="...">` or visually hidden text when creating new admin features or lists.
